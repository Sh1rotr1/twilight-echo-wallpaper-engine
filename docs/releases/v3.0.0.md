# 3.0.0 — 原生桥适配版（不修改本体）

这个版本只做一件事：**让插件适配 Twilight Echo 自带的渲染桥，不再改 `resources/app.asar`。**

## 变化

- 移除宿主补丁：不再生成 `app.asar.te-we-backup*`，不再在退出后自动打桥，不再需要
  `resources/core-node/runtime/node.exe`。
- 新增只读桥探测：启动时读 `out/renderer/we-background.js` 的 `BRIDGE_VERSION`，
  自动选择能力。
- 官方 Twilight Echo 2.0.2 的桥是 **v5**：
  - 保留：视频 / 网页 / 场景、画质、填充、暗化、X/Y/Z、缩放、壁纸属性、迷你播放器、播放页背景；
  - 不提供：轮播（定时/切页）与淡入。
- 轮播只在宿主桥 ≥ v9（历史/个人增强包）时出现；`playlist.ids` 等数据保留，原生模式下停止自动换图。
- `check-compat.mjs` 改为双模式检查，不再要求备份或安装器。
- `.tep` 不再附带 `patch/we-background.js`。

## 安装

1. 退出 Twilight Echo（含托盘）。
2. 安装 `com.twilightecho.tool.wallpaper-engine-3.0.0.tep`。
3. 启动后打开 设置 → 外观 → 背景与材质 → 动态壁纸。

## 已知边界

- 2.0.2 官方桥没有轮播，这是宿主能力，不是插件故障；插件不会尝试修改宿主来恢复。
- 外观页新增了一个同名“背景与材质”分类，宿主桥的卡片锚点可能在外观页打开时命中分类栏；
  这属于宿主桥逻辑，插件侧无法修正。
