# v2.4.2 — 适配 Twilight Echo 2.0.2

发布日期：2026-11-11
适配宿主：Twilight Echo 2.0.0 / 2.0.1 / **2.0.2**

## 变更

- 2.0.2 宿主桥仍是 v5，补丁器照常写回 v9；桥 / 入口 / CSP 三项锚点未变。
- **重试等待不再调用 `cmd /c timeout`**：无控制台 stdio 下该命令会失败，导致
  「rename 被占用 → 重试」抛异常。改用 `Atomics.wait` 同步睡眠。
- 备份 `app.asar.te-we-backup-2.0.2` 与 `app.asar.te-we-backup` 均为 2.0.2 原始包。
- 实测：`#te-we-bg` 挂载正常、外观页「动态壁纸」块可用。

## 附带文件

`bridge/we-background.js`（桥 v9）、`patch/we-background.js`、`lib/bridge-adapt.mjs`、
`lib/asar-lite.cjs`、`add-bridge.cmd`、`docs/HOST-BRIDGE.md`（手动添加宿主桥教学）。

## 升级方式

完全退出 Twilight Echo → 安装本版本 `.tep` → 启动一次再退出（或双击 `add-bridge.cmd`）。
