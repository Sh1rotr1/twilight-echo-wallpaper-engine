# 3.0.2 — CSP 写坏检测

v5 插件本身不修改宿主 CSP；本版只是让兼容性检查能识别外部补丁器造成的非法 CSP。

- `check-compat` 新增 `csp.valid` 与 `csp.invalid`，会指出 `img-src` / `media-src` / `frame-src`
  里夹在 source token 中的单引号（例如 `http://127.0.0.1:*'self'`）。
- 这类 CSP 会让 `'self'` 一起失效，表现为封面/本地图片被拦截、`resource.failed` 增多。
- 插件运行时仍只读检查宿主桥，不写 `app.asar`。
