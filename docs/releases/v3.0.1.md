# 3.0.1 — v5 原生桥适配

这个版本只做一件事：**让插件适配 Twilight Echo 自带的 v5 渲染桥，不修改 `resources/app.asar`。**

## 功能

- 外观页「动态壁纸」卡片：壁纸、画质、填充 / 暗化、X / Y / Z、缩放、壁纸属性。
- 视频、网页、场景壁纸；场景由 WebWallGL 3.x 实时渲染。
- 视频与网页自动静音，网页可交互。
- 迷你播放器 / 播放页背景开关。
- 插件设置面板：筛选、壁纸、应用 / 刷新 / 暂停 / 继续 / 关闭、额外目录、启动恢复。

## 说明

- 插件只读检查宿主 `out/renderer/we-background.js` 的 `BRIDGE_VERSION`，要求 ≥ 5。
- 不写 `app.asar`，不生成备份，不排队补丁。

## 安装

1. 退出 Twilight Echo（含托盘）。
2. 安装 `com.twilightecho.tool.wallpaper-engine-3.0.1.tep`。
3. 启动后打开 设置 → 外观 → 背景与材质 → 动态壁纸。
