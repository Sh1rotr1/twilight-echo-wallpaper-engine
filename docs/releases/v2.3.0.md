# v2.3.0 — 壁纸轮播

## 新增

- **壁纸轮播**：在外观 → 动态壁纸卡片的「轮播」行启用
  - 勾选任意多张壁纸（至少 2 张），按「列表循环」或「随机」顺序切换
  - 触发方式二选一：
    - **按时间**：每隔 1–120 分钟换一张
    - **切换页面**：在应用内切换内容页时换一张，带 15–120 秒冷却
  - 预览图垫底 + 420ms 淡入，切换不再闪黑
  - `暂停时停表`：暂停壁纸时轮播一起暂停
  - 窗口隐藏 / 全屏 / 交互模式时不触发切页
  - 失效壁纸自动跳过；重启后从上次游标继续，不补切
- 新增接口：`GET/POST /api/playlist`、`POST /api/playlist/action`、`POST /api/playlist/page`、`POST /api/playlist/context`
- 插件设置面板新增：轮播开关、方式、间隔、「下一张」

## 同时包含（2.2.0，此前未单独发布）

- 播放页背景开关 `playbackBg`
- 迷你播放器背景开关 `miniCover`；迷你窗口最高 720P、场景 30fps
- 渲染桥版本机制改为按 `BRIDGE_VERSION` 判断

## 升级说明

- 渲染桥升到 **v9**。安装 `.tep` 前请完全退出 Twilight Echo；应用更新会覆盖 `app.asar`，更新后需重新安装。
- 旧配置自动兼容：没有 `playlist` 字段时默认关闭轮播，单张模式行为不变。

- 定时切换、真实页面切换触发、冷却、互斥（定时模式下切页不生效）均已实测
